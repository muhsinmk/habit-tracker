# Habit Tracker 🧠✅

A simple and clean habit tracking app built with **React**, **Material-UI**, **Redux Toolkit**, and **Redux Thunk**. This app allows users to add, update, and track daily habits to help improve productivity and consistency.

---

## 🚀 Features

- Add, update, and delete habits
- Track habit completion by day
- Persistent state with Redux Toolkit
- Async actions using Redux Thunk
- Responsive UI with Material-UI

---

## 🛠 Tech Stack

- **React** – Frontend library for building UI
- **Redux Toolkit** – State management with simplified configuration
- **Redux Thunk** – Middleware for async logic
- **Material-UI (MUI)** – UI components and design
- **LocalStorage** (or your chosen backend) – Data persistence

---

## 📦 Installation

```bash
git clone https://github.com/muhsinmk/habit-tracker.git
cd habit-tracker
npm install
```
